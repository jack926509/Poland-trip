## 交叉審查與回歸修正

獨立 AI 審查在第一輪發現：單檔版點選搜尋結果後，網址與頁面雖正確，但單次 `requestAnimationFrame()` 可能被瀏覽器原生 hash 導航時序覆蓋，沒有捲到指定小節。

修正方式：先加入會失敗的回歸契約測試，再將單檔章節切換改為雙層 `requestAnimationFrame()`，等待 hash 預設導航與版面更新完成後才執行 `scrollIntoView()`。

修正後以 Chrome 390×844 真實點擊「華沙 → 克拉科夫」結果：
