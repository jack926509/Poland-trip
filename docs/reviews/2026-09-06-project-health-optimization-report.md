## 畫面層驗收

- 1280px：首頁 `scrollWidth = innerWidth = 1280`；圖片 0 破圖；導覽三組可展開；遮罩、Escape 與焦點返回正常。
- 768px：多頁版與單檔版均無水平溢出；選單邊界位於視窗內。
- 390px：首頁、Day 7、華沙城市頁、資料庫與單檔版均無水平溢出。
- 320px：多頁版與單檔版 `scrollWidth = innerWidth = 320`；選單範圍為 20–300px；刊頭文字寬與容器同為 142px。
- 390px 單檔刊頭修正後，文字 `scrollWidth` 由 225px 降為 177px，與容器等寬。
- 深色模式 CSS media 規則存在；從實際頁面 CSSOM 讀取 token 後計算，主要組合對比為 7.15:1–15.01:1。此項為規則與對比計算驗收，未切換作業系統外觀截圖。
- 所有已驗收頁面的瀏覽器 console 為 0 錯誤。
