## 獨立審查發現與處理

第一輪獨立審查無 P0、P1，共提出 5 項 P2 與 3 項 P3；已逐項修正：

1. 索引可能納入未知私人欄位與私人資料卡：改採公開欄位白名單，頁級索引排除私人標記，加入正式建置輸出防洩漏測試。
2. `E. Wedel` 與 `E.Wedel` 形成重複餐廳與 ID：加入名稱標點正規化及全索引唯一 ID 測試。
3. 多詞標題查詢排序錯誤：所有查詢詞皆命中標題時，優先於一般關鍵詞結果。
4. 搜尋與首頁必要資訊低於 16 px：必要文字統一提高至至少 1rem。
5. 多頁及單檔版前後章節導覽低於 44 px：導覽改為 flex 置中並設定 44 px 最小高度。
6. `Wroclaw` 等無變音符號查詢失效：搜尋字串採 NFKD 正規化、移除組合音標並處理 `ł`。
7. 搜尋元件的 `aria-expanded` 語意不適用，快捷分類缺少群組語意：移除該屬性並補上 `role="group"`。
8. Escape 只在輸入框聚焦時生效：鍵盤事件移至搜尋元件根節點，重設後將焦點返回輸入框。

最終獨立複核確認原先 8 項問題全部關閉且沒有新的 P0–P2，另發現單檔版「下一頁」在改為 flex 後文字未靠右的 P3 視覺回歸。推送前已加入 `justify-content: flex-end` 與回歸契約測試，沒有保留中的審查問題。
