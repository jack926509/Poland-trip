## 一、目標

完成 PR #49 後仍存在的資料正確性缺口，讓網站上的行程時間、景點票價、開放規則與地圖圖釘都有可追溯的來源及明確的查證狀態；無法取得可靠來源的資料保留為待確認，不以推算值假裝已驗證。

## 五、風險與處理方式

| 風險 | 影響 | 處理方式 |
|---|---|---|
| 地理編碼服務被封鎖 | 無法完成 34 筆座標驗證 | 觸發停止條件，保留證據，不猜測、不宣稱完成 |
| 店家或場館官網為動態頁 | 票價／營業時間難以抓取 | 改查官方售票系統、官方公告或直接標示待確認 |
| 同一資料散落多檔 | 修一處但其他頁保留舊值 | 增加跨檔一致性測試；長期再評估單一 `venueFacts` 資料源 |
| Claude 分支與 `main` 分岔 | 直接合併可能重帶已合併內容或衝突 | 逐項移植，不做整分支 merge |
| 圖釘改正但名稱對錯店 | 導航到同城錯誤分店 | 先確認官方地址與分店，再做地理編碼 |
| 動態票價在出發前再次變更 | 網站資訊可能過期 | 保存 `checkedAt`，並維持出發前 7 天複查待辦 |
