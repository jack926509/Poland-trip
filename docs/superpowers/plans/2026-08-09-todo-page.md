# 待辦事項分頁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增依類別整理 13 項旅遊待辦的靜態網站與單檔版分頁。

**Architecture:** 在既有 `trip.js` 建立 `todoGroups`，讓新模板與測試共用同一來源。`build.mjs` 產生新靜態頁並把它併入單檔版實用資訊選單。

**Tech Stack:** Node.js ESM、靜態 HTML、CSS、node:test。

## Global Constraints

- 只呈現公開的處理資訊，不呈現私人訂單、付款或證件資料。
- 待辦總數必須為 13，分類順序固定為交通、景點、餐飲、雨天備案。
- 單檔版必須保留一次一個章節的切換行為。

**Interfaces:**
- Produces: `todoGroups`，每組具有 `id`、`title`、`items`；每項具有 `date`、`name`、`status`、`action`、`url`。

- [ ] **Step 1: 寫入待辦群組資料**

```js

```

- [ ] **Step 2: 新增 `renderTodos({ todoGroups })`**

```js

  return renderPracticalLayout('待辦事項', 'Action list', '13 項...', content);

```

- [ ] **Step 3: 在 `build.mjs` 寫出 `practical/todos.html`，並加入 `standalonePages`**

```js

```
