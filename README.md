# POLSKA — 2026 波蘭四城旅遊規劃

這是一個以「現在方便規劃旅遊」為優先的桌機靜態網站。內容整合原本的 8 天行程資料與新版四城指南的 2026-08 資料，產出 21 個互相連結的頁面。

## 網站內容

- 首頁：8 天總覽、P0 未完成數、最近確認期限、ETIAS 與離線包狀態
- 每日行程：時間表、現場地址、入口、官網、待確認步驟、備案與晚間準備
- 城市指南：華沙、克拉科夫、樂斯拉夫、波茲南的 Leaflet 互動地圖、景點與餐廳
- 實用資訊：訂票、米其林、門票、市內交通、購物、安全與行前提醒
- 自由行資料庫：依城市、類別、狀態查找，含 SOS 離線卡、五種緊急流程、查證日與重查日

所有頁面內容由 `src/data/*.js` 產生；要更新票價、車班或餐廳時，只改資料檔，不逐頁修改 HTML。

## 本機使用

```bash
npm run build
python3 -m http.server 8080 --directory dist
```

瀏覽器開啟 `http://localhost:8080/`。

## 驗收

```bash
npm test
env -u NODE_OPTIONS ./verify.sh
```

`npm test` 會重新產生網站並檢查 21 頁、所有本機連結、50 個地圖圖釘、資料契約、每日步驟覆蓋與繁體中文。`./prepare-site.sh <空目錄>` 會建立 GitHub Pages／Cloudflare Pages 的正式部署內容。

## 舊版

舊桌機分章雜誌、手機 PWA、爬蟲整合來源與設計參考都保留在 `archive/`，不會進入正式網站。新版目前不註冊 PWA；根目錄的 `sw.js` 只用來清除已安裝舊版留下的快取。
